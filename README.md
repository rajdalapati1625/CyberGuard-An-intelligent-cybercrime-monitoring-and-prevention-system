# CyberGuard: Intelligent Cybercrime Monitoring and Prevention System

CyberGuard is a machine-learning-based project designed to identify potentially malicious URLs and classify scam or spam messages.

## Features
- URL threat classification using Random Forest and lexical features
- Scam and spam message classification using TF-IDF and Multinomial Naive Bayes
- FastAPI backend for detection workflows
- MongoDB storage and dashboard-based threat analytics

## Technologies Used
Python, scikit-learn, FastAPI, MongoDB, TF-IDF, Random Forest, Naive Bayes
